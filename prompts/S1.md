# S1: Binary Tree Traversals Prompts (55_q3.rkt)

## Prompt 1: tree-height 

Write only (tree-height tree) for a binary tree that is either '() or
(value left right). The height of '() is 0 and the height of a node is
1 plus the larger of its subtrees' heights. Start the file with
#lang racket/base. Add a comment with the recursive reading. Nothing else.


## Prompt 2: leaf-count 

Write only (leaf-count tree). A leaf is a node whose left and right are
both '(). The empty tree has 0 leaves. Add a comment with the recursive
reading. Nothing else.


## Prompt 3: inorder-acc 

Write only (inorder-acc tree acc). It returns the inorder list of the
values of tree (left, node, right) placed in front of the list acc,
without using append or reverse. Hint: process the right subtree first,
cons the node value, then process the left subtree. Nothing else.


## Prompt 4: preorder-acc 

Write only (preorder-acc tree acc), in the same style as inorder-acc,
returning node, left, right order in front of acc. No append, no reverse.


## Prompt 5: postorder-acc 

Write only (postorder-acc tree acc), in the same style, returning left,
right, node order in front of acc. No append, no reverse.


## Prompt 6: print-inorder 

Write only (print-inorder tree). It uses inorder-acc with '() as the
initial accumulator, prints the list with display on one line, and ends
with (newline). The empty tree must print ().


## Prompt 7: print-all-traversals 

Write only (print-all-traversals tree). It prints three lines with
display: the inorder list, the preorder list, then the postorder list,
each followed by (newline). Reuse the existing helpers.


## Prompt 8: print-height-and-leaves 

Write only (print-height-and-leaves tree). It prints the two-element
list (height leaf-count) with display on one line, followed by (newline).
Reuse tree-height and leaf-count. The empty tree prints (0 0).


## Prompt 9: self-review
