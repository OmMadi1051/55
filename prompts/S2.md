# S2 Prompts (Conditional Insert, id_q4.rkt)


### Prompt 1: my-length  
```
Write only (my-length lst), a tail-recursive length for a proper list
using an accumulator. Start the file with #lang racket/base. Add a
comment with the recursive reading. Nothing else.
```

### Prompt 2: my-reverse
```
Write only (my-reverse lst), a tail-recursive reverse using an
accumulator. Add a comment with the recursive reading. Nothing else.
```

### Prompt 3: my-map
```
Write only (my-map f lst). It applies f to each element in order and
returns the list of results. It must be tail-recursive: use an
accumulator and my-reverse. No built-in map. Add a recursive-reading
comment. Nothing else.
```

### Prompt 4: list-like?
```
Write only (list-like? e), true when e is '() or a pair, using only
allowed built-ins (list? is not allowed). Add a comment. Nothing else.
```

### Prompt 5: insert-if-short
```
Write only (insert-if-short x lst n). It inserts atom x at the front of
every list, at every level of nesting, whose length is less than n.
The length is the number of top-level elements of the ORIGINAL list,
measured before insertion. The top-level list is treated like every
other list, and '() has length 0 so it becomes (x) when 0 < n. Use
my-length, my-map and list-like?. Elements that are not lists stay
unchanged. Add a recursive-reading comment. Nothing else.
```


### Prompt 6: make-inserter
```
Write only (make-inserter x len-ok?). It returns a function of one
argument (a list) that inserts x at the front of every list, at every
level of nesting, whose length satisfies len-ok?, a function taking one
number. Length is measured on the original list. Use my-length, my-map
and list-like?. Add a recursive-reading comment. Nothing else.
```

### Prompt 7: rewrite insert-if-short
```
Rewrite only (insert-if-short x lst n) so that it is defined using
make-inserter, with len-ok? being a function that checks length < n.
Remove the old definition so the file contains exactly one definition
of insert-if-short. Nothing else.
```

### Prompt 8: print-insert-result
```
Write only (print-insert-result), taking no arguments. It reads x, lst
and n with read, in that order, from standard input, then prints the
result of insert-if-short with display, followed by (newline). No
prompts and no other output. Nothing else.
```


### Prompt 9: review
```
Review the final id_q4.rkt only against the scheme-dev self-review
checklist. List any identifier that is not in the allowed built-ins, any
top-level call or print, any helper missing its recursive-reading
comment, and whether insert-if-short is defined exactly once. Do not
rewrite the code, only report.
